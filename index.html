🟡 Kakao API Everything

카카오 디벨로퍼스의 주요 API를 브라우저에서 바로 테스트하는 플레이그라운드

SDK 설정

카카오 디벨로퍼스 내 애플리케이션에서 발급받은 키를 입력하세요. 키는 이 브라우저의 localStorage에만 저장됩니다.

사전 준비 체크리스트
  1. 내 애플리케이션 → 앱 설정 → 플랫폼 → Web에 현재 도메인() 등록
  2. 제품 설정 → 카카오 로그인 활성화 + Redirect URI 등록
  3. 동의항목에서 닉네임/프로필 사진 등 필요한 항목 설정
  4. 지도 사용 시: 앱 설정 → 플랫폼 → Web 도메인 등록만으로 사용 가능

REST API 테스터 (curl 생성기)

⚠️ 카카오 REST API는 대부분 브라우저 CORS를 허용하지 않으므로, 여기서는 바로 실행 가능한 curl 명령을 생성합니다. 터미널이나 서버에서 실행하세요. REST API 키/액세스 토큰은 절대 프론트엔드 코드에 넣지 마세요. 
curl 명령이 여기에 생성됩니다.

배포 가이드 (GitHub Pages)

  1. 이 저장소의 Settings → Pages에서 Source를 Deploy from a branch, 브랜치를 main(또는 배포 브랜치) / root로 설정합니다.
  2. 배포 URL(https://<계정>.github.io/kakaoapi_everything/)을 확인합니다.
  3. 카카오 디벨로퍼스 → 내 애플리케이션 → 앱 설정 → 플랫폼 → Web에 배포 URL의 도메인을 등록합니다.
  4. 카카오 로그인 사용 시 Redirect URI에도 배포 URL을 등록합니다.
  5. 배포된 페이지의 설정 탭에서 JavaScript 키를 입력하고 각 기능을 테스트합니다.

이 프로젝트는 순수 정적 파일(HTML/CSS/JS)이라 Netlify, Vercel, Cloudflare Pages 어디든 그대로 배포됩니다.

Kakao API Everything — 학습·테스트 용도. 키는 브라우저에만 저장되며 서버로 전송되지 않습니다.
